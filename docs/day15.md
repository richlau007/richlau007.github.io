# Day 15：性能优化

## 复习要点
- 资源加载优化（懒加载、预加载、压缩合并）
- 代码分割与按需加载
- 缓存机制（强缓存、协商缓存）
- 节流与防抖
- 前端监控与性能分析

## 典型面试题与答案
1. **如何优化页面加载速度？**
   - 答：图片懒加载、资源压缩合并、CDN加速、减少HTTP请求、代码分割等。
   - 解释：优化加载速度提升用户体验和SEO。
2. **节流和防抖的区别？**
   - 答：节流是规定时间内只执行一次，防抖是事件停止一段时间后才执行。
   - 解释：常用于高频事件处理，如滚动、输入。
3. **前端常见的缓存策略有哪些？**
   - 答：强缓存（Expires/Cache-Control）、协商缓存（Last-Modified/Etag）。
   - 解释：合理利用缓存可减少请求、提升性能。
4. **如何监控和分析前端性能？**
   - 答：使用Performance、Lighthouse、埋点、日志上报等工具。
   - 解释：监控和分析有助于发现瓶颈并持续优化。
