- 常见攻击防护措施

## 典型面试题与答案
1. **前端如何防御XSS攻击？**
   - 答：输入校验、输出转义、CSP策略等。
   - 解释：防止恶意脚本注入和执行。
2. **什么是JWT？常见应用场景？**
   - 答：JWT是一种基于JSON的令牌，用于身份认证和信息传递。
   - 解释：常用于前后端分离的登录认证。
3. **对称加密和非对称加密的区别？**
   - 答：对称加密用同一密钥加解密，非对称加密用公钥加密私钥解密。
   - 解释：非对称加密更安全，常用于密钥交换。
4. **如何防止CSRF攻击？**
   - 答：使用Token校验、SameSite Cookie、Referer校验等。
   - 解释：防止第三方网站冒用用户身份操作。
