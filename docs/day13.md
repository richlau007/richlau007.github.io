## 典型面试题与答案
1. **什么是单例模式？**
   - 答：全局只存在一个实例的模式。
   - 解释：常用于全局状态管理，如Vuex、Redux store。
2. **工厂模式的作用？**
   - 答：通过工厂函数创建对象，隐藏创建细节。
   - 解释：便于扩展和维护。
3. **观察者和发布订阅的区别？**
   - 答：观察者是被观察者主动通知，发布订阅有中间调度中心。
   - 解释：发布订阅更解耦，适合复杂系统。
4. **如何用JS实现发布订阅？**
   - 答：维护事件列表，on订阅，emit发布，off取消。
   - 解释：常用于事件总线、消息通知等场景。
