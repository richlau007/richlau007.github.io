# Day 19：CI/CD与自动化测试

## 复习要点
- 持续集成（CI）与持续部署（CD）概念
- 常用CI/CD工具（GitHub Actions、Jenkins、GitLab CI等）
- 自动化测试（单元测试、集成测试、端到端测试）
- 常用测试框架（Jest、Mocha、Cypress）
- 代码覆盖率与测试报告

## 典型面试题与答案
1. **什么是CI/CD？**
   - 答：CI是持续集成，自动化构建、测试、集成代码；CD是持续部署，自动化发布到生产环境。
   - 解释：CI/CD提升开发效率和交付质量。
2. **常见的自动化测试类型有哪些？**
   - 答：单元测试（测试最小功能单元）、集成测试（测试模块间协作）、端到端测试（测试完整流程）。
   - 解释：不同测试类型覆盖不同层级，保障系统稳定。
3. **Jest和Cypress的区别？**
   - 答：Jest主要用于单元测试，Cypress用于端到端测试。
   - 解释：选择合适工具能提升测试效率和覆盖率。
4. **如何集成自动化测试到CI流程？**
   - 答：在CI脚本中添加测试命令，构建时自动执行测试并生成报告。
   - 解释：自动化测试能及时发现问题，防止bug上线。
