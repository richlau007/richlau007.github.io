# Day 14：浏览器渲染流程、回流与重绘

## 复习要点
- 浏览器渲染流程（解析HTML、构建DOM/CSSOM、渲染树、布局、绘制）
- 回流（重排）与重绘的区别
- 触发回流/重绘的常见操作
- 如何减少回流与重绘

## 典型面试题与答案
1. **浏览器渲染流程是怎样的？**
   - 答：解析HTML生成DOM树，解析CSS生成CSSOM树，合成渲染树，布局计算，最后绘制到屏幕。
   - 解释：理解渲染流程有助于优化性能和排查页面问题。
2. **回流和重绘的区别？**
   - 答：回流会引发布局和几何属性的重新计算，重绘只影响外观（如颜色），不影响布局。
   - 解释：回流比重绘更消耗性能，应尽量减少。
3. **哪些操作会触发回流？**
   - 答：添加/删除DOM节点、修改元素尺寸/位置、读取offset/scroll等属性。
   - 解释：频繁操作DOM会导致多次回流，影响性能。
4. **如何减少回流和重绘？**
   - 答：合并DOM操作、使用文档片段、避免逐条修改样式、用transform/opacity代替top/left等。
   - 解释：优化DOM操作能显著提升页面性能。
