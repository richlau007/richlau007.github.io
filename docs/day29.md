# Day 29：项目经验梳理与高频面试题

## 复习要点
- 梳理个人项目经历与技术选型
- 项目中遇到的难点与解决方案
- 高频前端面试题总结
- 简历优化与面试技巧

## 典型面试题与答案
1. **请介绍一个你主导或参与的项目？**
   - 答：简要描述项目背景、目标、技术栈、你的主要工作和亮点。
   - 解释：突出个人贡献和技术深度，体现团队协作和问题解决能力。
2. **项目中遇到的最大技术难题是什么？如何解决？**
   - 答：描述具体问题、分析过程、尝试方案和最终解决办法。
   - 解释：展现你的分析能力、学习能力和责任心。
3. **你如何保证项目的性能和安全？**
   - 答：采用性能优化（懒加载、缓存、代码分割）、安全防护（XSS/CSRF防御、权限校验等）。
   - 解释：体现对前端全局质量的关注。
4. **前端高频面试题有哪些？**
   - 答：如事件循环、闭包、原型链、虚拟DOM、性能优化、安全防护等。
   - 解释：提前准备高频题，提升面试通过率。

## 推荐实践
- 梳理并复盘自己的项目经历
- 总结高频面试题并自测
