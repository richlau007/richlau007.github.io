# Day 03：HTML5新特性

## 复习要点
- 新增语义化标签（header、nav、main、section、article、aside、footer）
- 多媒体标签（audio、video）
- canvas绘图、svg
- 本地存储（localStorage、sessionStorage、IndexedDB）
- 新表单控件和属性

## 典型面试题与答案
1. **HTML5新增了哪些语义化标签？**
   - 答：header、nav、main、section、article、aside、footer。
   - 解释：这些标签让页面结构更清晰，便于分区和内容管理。
2. **audio和video标签的常用属性有哪些？**
   - 答：src、controls、autoplay、loop、muted、poster（video专有）等。
   - 解释：这些属性让多媒体内容更易于控制和交互，提升用户体验。
3. **localStorage和sessionStorage的区别？**
   - 答：localStorage持久存储，sessionStorage会话级存储，页面关闭即清空。
   - 解释：合理选择存储方式有助于数据安全和性能优化。
4. **canvas和svg的区别？**
   - 答：canvas是位图，适合高频率绘制；svg是矢量图，适合静态图形。
   - 解释：canvas适合游戏、动画等场景，svg适合图标、图表等可缩放场景。

## 推荐实践
- 用audio/video标签插入多媒体
- 用canvas或svg画一个简单图形
- 使用localStorage存取数据
