# Day 03：HTML5新特性

## 复习要点
- 新增语义化标签（header、nav、main、section、article、aside、footer）
- 多媒体标签（audio、video）
- canvas绘图、svg
- 本地存储（localStorage、sessionStorage、IndexedDB）
- 新表单控件和属性

## 典型面试题与答案
1. **HTML5新增了哪些语义化标签？**
   - header、nav、main、section、article、aside、footer。
2. **audio和video标签的常用属性有哪些？**
   - src、controls、autoplay、loop、muted、poster（video专有）等。
3. **localStorage和sessionStorage的区别？**
   - localStorage持久存储，sessionStorage会话级存储，页面关闭即清空。
4. **canvas和svg的区别？**
   - canvas是位图，适合高频率绘制；svg是矢量图，适合静态图形。

## 推荐实践
- 用audio/video标签插入多媒体
- 用canvas或svg画一个简单图形
- 使用localStorage存取数据
