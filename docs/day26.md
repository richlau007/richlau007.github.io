## 典型面试题与答案
1. **如何实现防抖函数？**
   - 答：防抖函数在事件触发n毫秒后执行，若期间再次触发则重新计时。
   - 解释：常用于输入框搜索、窗口resize等高频事件。
2. **如何实现深拷贝？**
   - 答：递归遍历对象和数组，复制每一层属性，注意循环引用。
   - 解释：深拷贝可避免对象引用带来的副作用。
3. **手写Promise的基本实现思路？**
   - 答：维护状态（pending/fulfilled/rejected），支持then链式调用，异步执行回调。
   - 解释：理解Promise原理有助于掌握异步编程。
4. **链表反转的实现？**
   - 答：用三个指针遍历链表，逐步反转next指向。
   - 解释：链表操作是高频算法题，考察指针操作能力。
