## 典型面试题与答案
1. **数组和链表的区别？**
   - 答：数组支持随机访问，插入删除慢；链表插入删除快，访问慢。
   - 解释：根据需求选择合适的数据结构。
2. **栈和队列的应用场景？**
   - 答：栈用于递归、括号匹配，队列用于消息队列、广度优先搜索等。
   - 解释：理解应用场景有助于算法设计。
3. **哈希表的原理？**
   - 答：通过哈希函数将键映射到数组索引，实现高效查找。
   - 解释：哈希冲突需用链表或开放地址法解决。
4. **树和图的区别？**
   - 答：树是无环连通图，图可有环，节点间关系更复杂。
   - 解释：树适合层级结构，图适合复杂网络。
