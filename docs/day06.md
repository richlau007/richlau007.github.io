# Day 06：响应式设计、媒体查询、移动端适配

## 复习要点
- 响应式设计理念（流式布局、弹性图片、断点）
- 媒体查询语法与常用断点
- 移动端适配方案（rem/em、viewport、flexible.js等）
- 移动端常见兼容性问题

## 典型面试题
1. 响应式和自适应的区别？
   - 答：响应式通过媒体查询等技术适配不同屏幕，自适应通过百分比等自动调整布局。
   - 解释：响应式更灵活，适合多终端；自适应实现简单，适合需求单一场景。
2. 媒体查询的常见用法？
   - 答：@media screen and (max-width: 600px) { ... }，根据屏幕宽度等条件切换样式。
   - 解释：媒体查询是响应式设计的核心，能针对不同设备定制样式。
3. 移动端适配常用方案有哪些？
   - 答：rem/em布局、viewport设置、flexible.js、媒体查询、vw/vh单位等。
   - 解释：不同方案适应不同项目需求，提升移动端体验。
4. 如何处理移动端1px问题？
   - 答：使用transform缩放、border-image、伪元素等方式实现物理1px。
   - 解释：高分屏下1px实际宽度大于1物理像素，需特殊处理保证视觉一致。
