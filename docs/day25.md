# Day 25：常用算法

## 复习要点
- 排序算法（冒泡、选择、插入、快排、归并等）
- 查找算法（二分查找、顺序查找）
- 递归与分治
- 动态规划、贪心算法

## 典型面试题与答案
1. **常见的排序算法及其复杂度？**
   - 答：冒泡/选择/插入O(n^2)，快排/归并O(nlogn)。
   - 解释：根据数据规模和有序性选择合适算法。
2. **二分查找的前提条件？**
   - 答：数据有序。
   - 解释：无序数据需先排序。
3. **递归和迭代的区别？**
   - 答：递归通过函数自身调用，迭代用循环实现。
   - 解释：递归代码简洁，迭代效率高。
4. **动态规划的核心思想？**
   - 答：将大问题拆解为子问题，保存子问题结果避免重复计算。
   - 解释：适合有重叠子问题和最优子结构的问题。
