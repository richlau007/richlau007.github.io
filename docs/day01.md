# Day 01：HTML基础标签、语义化、结构布局

## 复习要点
- 常用HTML标签（div、span、a、img、ul、li、table等）
- 语义化标签（header、nav、main、section、article、aside、footer等）
- HTML文档结构与规范
- DOCTYPE声明、meta标签

## 典型面试题与答案
1. **常见的HTML标签有哪些？分别适合什么场景？**
   - 常见标签有div（布局容器）、span（行内文本）、a（超链接）、img（图片）、ul/li（列表）、table（表格）等。语义化标签如header、nav、main等用于结构化页面。
2. **什么是语义化标签？为什么要使用？**
   - 语义化标签能更好地描述内容结构，提升可读性、SEO和无障碍性。
3. **HTML5新增了哪些语义化标签？**
   - 新增header、nav、main、section、article、aside、footer等。
4. **DOCTYPE的作用是什么？**
   - 声明文档类型，告诉浏览器以何种模式解析页面，避免怪异模式。

## 推荐实践
- 用语义化标签搭建一个简单页面结构
- 检查页面结构的可访问性
